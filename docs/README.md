# docs/

- `design/` — specs and plans. See `design/README.md` for how specs and
  plans are structured (Arcs, Slices, Tasks, tags).
- `diagrams/` — diagrams per `.claude/rules/diagram-standards.md`,
  stored separately from specs/plans rather than inline.
- `tooling/` — standalone tooling notes not tied to a specific spec
  (e.g. `tooling/submodule-upgrade.md`).

**Not yet built:** an agent-first developer documentation and
cross-referencing system — living docs meant to help an agent (or a
human) orient in the codebase quickly (e.g. module maps, glossaries,
links between specs/plans/code), as distinct from the point-in-time
specs and plans above. This needs its own `/superpowers:brainstorm` pass
before it exists; noted here so the intent isn't lost.
